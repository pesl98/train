Language: Arduino C++ (subset)

Write void setup() and void loop() as on a real board. Your own functions may call delay().

Works: int/long/byte/bool/char/float/String variables, const, #define NAME value, 1-D arrays, if/for/while/do/switch, ?:, casts, integer division like C++.

Not supported: classes, structs, pointers, references, static locals, other libraries (WiFi, Wire…), interrupts, RTOS.

Notes

This is a translator for a teaching subset, not a compiler: the sketch runs on a simulated clock (about 20 µs per loop() pass), not cycle-accurate.

Pins are numbered 0–7. Outputs are 25 Ω drivers; inputs read high above half the supply voltage.

Older JavaScript sketches (function setup()) still run.
